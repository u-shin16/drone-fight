# Tello Connect

2台のTello EDUを、それぞれのPCからルーター経由で操作するローカル対戦アプリです。Tello EDUのミッションパッド1〜8で位置を補正します。

## 起動

各PCでPython 3.10以上を用意します。

```sh
python3 -m pip install -r requirements.txt
python3 app.py
```

表示された `http://127.0.0.1:5050` を開きます。ドローンと2台のPCを同じWi-Fiに接続し、それぞれのPCで自分の機体を選びます。初回にTelloのWi-Fiからルーターへ切り替える操作はアプリの「設定」画面で行います。

## 対戦の準備

1. パッド1〜8を番号が見える面で床に置き、ロケットの絵をすべて同じ向きにそろえます。パッド同士の間隔や配置全体の場所は自由ですが、A機がパッド4、B機がパッド6の中心から離陸できるようにします。
2. 「1. ドローンを探す」で各PCが自分の機体を選び、「2. マッチング」で同じ4桁の合言葉を使います。
3. バトル画面で、全8枚と周囲の空き範囲が写ったJPEG/PNG写真を選びます。ロケットの向きが写真の右に見えるように撮ります。画面の案内どおり、基準パッドの四隅、1〜8の中心、飛行可能な長方形の対角2点、遠くの別パッドの四隅を順に指定します。約20cm角のパッドから相対距離を計算し、2枚目の寸法で写真の遠近変換を検査します。写真はPC内で処理し、座標だけを保存します。
4. 片方のPCで地図を保存すると、もう片方へ自動で届きます。両PCで異なる地図を保存していた場合はA側の設定が優先されます。両PCで地図が一致しない間は「準備OK」に進めません。配置を変えたら撮り直します。
5. ドローンの周囲と写真で選んだ飛行範囲から人・壁・家具を十分離し、プロペラガードを取り付けます。両機をパッド4・6の中心に相手向きで置きます。
6. 作戦を選び、両PCで「準備OK」を押します。5秒後に離陸し、各機が開始パッドを確認してから移動します。パッドが読めない・番号が違う場合は着陸します。

バトル中の「降参」は着陸、「緊急停止」はプロペラ停止です。Esc・Ctrl+C・⌘Cでも降参できます。制限時間は60秒です。

## 位置と飛行範囲

地図のXはパッドのロケットの向き、Yはその右側です。パッドが見える間は状態パケットの `mid/x/y` で位置を補正します。見えない間は移動命令から予測するため、誤差は蓄積します。写真で指定した飛行範囲の外へ向かう命令は止めて着陸します。これは壁や人を検出する機能ではありません。

下向きカメラによるパッド検出の公式範囲は高さ0.3〜1.2mです。明るさ、表面、機体の高さで検出できないことがあります。写真スキャンの座標は、20cmというパッド寸法と人が指定した点の精度に依存します。

## 検証と限界

`python3 -m unittest discover -s tests` で地図の検証を実行できます。`python3 tests/pad_battle.py 1_attack 2_flee 12 1 irregular` は2台の偽Telloによる不規則配置の模擬戦です。実機での飛行、写真の現場寸法、2台同時通信、壁・人との離隔はまだ検証が必要です。模擬戦の数値は実機の精度や安全を保証しません。
