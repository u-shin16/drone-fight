# Tello Connect

2台のTello EDUを、それぞれのPCからルーター経由で操作するローカル対戦アプリです。最初にドローン自身が飛んでミッションパッド1〜8の位置を測って地図を作り、対戦中はパッドで位置を補正します。

## 起動

各PCでPython 3.10以上を用意します。

```sh
python3 -m pip install -r requirements.txt
python3 app.py
```

表示された `http://127.0.0.1:5050` を開きます。ドローンと2台のPCを同じWi-Fiに接続し、それぞれのPCで自分の機体を選びます。初回にTelloのWi-Fiからルーターへ切り替える操作はアプリの「設定」画面で行います。

## 対戦の準備

1. パッド1〜8を、奥から **「1 2 3 ／ 4 5 6 ／ 7 8」** の並びで、数字の面を上にして床に置きます。間隔や部屋の中の位置は自由です。ロケットの絵は8枚とも同じ向き（パッド4から6の方へ向く向き）にそろえ、パッド4と6は100cm以上離します。
2. 「1. ドローンを探す」で、各PCが自分の機体を「自分の機体にする」で選びます。
3. **フィールドのスキャン（片方のPCで1回）**: 「フィールド」画面で、パッド4から測って壁・人・家具にぶつからずに飛べる距離（後ろ・前・奥・手前、各50〜600cm）を入れ、自分の機体をパッド4の中心にロケットの向きで置いて「スキャン開始」を押します。機体は高さ100cm・秒速40cmで、その長方形の内側（端から30cm）を往復しながら50cmごとに止まってパッドを読みます。見えた回数が足りないパッドは見に戻り、最後にパッド4へ戻って着陸します。保存するのは、8枚とも2回以上見え、同じパッドの位置が25cm以内でそろい、パッド4に戻ったときのズレが30cm以内で、番号の並びが正しいときだけです。どれかが満たせないとき、または停止ボタン（Esc）・状態の途切れ（1.5秒）・電池25%未満・向きのずれ20°超・移動命令の3連続失敗・時間切れ（範囲の広さに応じて最大6分）のときは、着陸して保存しません。開始には電池50%以上が必要です。写真は使いません。
4. 保存した地図はマッチした相手のPCへ自動で届きます。両方のPCに地図があるときは新しくスキャンした方にそろえます。両PCの地図が一致するまで「準備OK」に進めません。配置を変えたらスキャンし直します。
5. 「2. マッチング」で同じ4桁の合言葉を使い、バトル画面で作戦を選びます。A機はパッド4の中心にロケットの向き、B機はパッド6の中心に反対向きで置き、両PCで「準備OK」を押すと5秒後に離陸します。各機は開始パッドを確認してから動き、パッドが読めない・番号が違うときは着陸します。

バトル中の「降参」は着陸、「緊急停止」はプロペラ停止です。Esc・Ctrl+C・⌘Cでも降参できます。制限時間は60秒です。

## 位置と飛行範囲

地図のXはパッドのロケットの向き、Yはその右側です。パッドが見える間は状態パケットの `mid/x/y` で位置を補正します。見えない間は移動命令から予測するため、誤差は蓄積します。スキャンで指定した飛行範囲の外へ向かう命令は止めて着陸します。これは壁や人を検出する機能ではありません。

下向きカメラによるパッド検出の公式範囲は高さ0.3〜1.2mで、見える広さは高さ0.3mで40cm四方、1.2mで1m四方です。明るさ、床の色、機体の高さで検出できないことがあります。スキャンした地図の精度は、パッドとパッドの間を移動するときのTelloの移動誤差に左右されます。

## 検証と限界

- `python3 -m unittest discover -s tests` … 地図・スキャン（範囲、往復ルート、パッドの位置合わせ、保存しない条件）・安全の単体テスト。
- `python3 tests/scan_sim.py normal` … 偽のTelloでスキャンを最初から最後まで飛ばし、保存した地図と本当のパッド位置の差を表示します。`rough`（移動のズレ20%）、`missing7`（パッド7なし）、`state-drop`（状態の途切れ）、`stop`（途中で停止）、`start5`（パッド5から離陸）、`yaw`（向きのずれ）も選べます。
- `python3 tests/pad_battle.py 1_attack 2_flee 12 1 irregular` … 2台の偽Telloによる不規則配置の模擬戦です。

偽Telloの結果は、偽Telloの動き方（移動のズレ、カメラの見える範囲＝高さ×約0.42の半径）を前提にしたもので、実機の精度や安全を保証しません。実機でのスキャン・飛行、2台同時の通信、壁・人との離隔はまだ検証していません。
